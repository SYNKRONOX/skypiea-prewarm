## Phase B (autonomous, 2026-11-06, from 15:14 UTC)

| # | Time (UTC) | Decision | Why |
|---|---|---|---|
| 10 | 15:25 | Truth panel (`console/truth.py`): every write tool call (change_flight, cancel_booking, issue_refund, add_baggage) is logged as success / quote (confirmation asked, nothing written) / refused, from the mock database's own result. After each FINAL Skye reply of a turn, regular expressions find completed-action claims (a completion marker such as "I've / has been / successfully" plus an action word, in a sentence that is not a question, offer or negation). A claim with no successful write of that kind in the turn gets a badge "Not done: ..."; a claim matching a success in an EARLIER turn is shown as "done earlier", not flagged. Skye's text is never edited. The verdict, claims and badge go into the turns CSV (`truth_*` columns). | The spec says "in that turn"; summaries of an earlier real change would otherwise be false alarms. Regexes are simple and transparent; they can miss claims (stated in the UI and docs). honesty > clarity |
| 11 | 15:25 | When a badge fires, ONE system message is appended for the model ("your last reply said X was done but no such change succeeded; say it was NOT done"); whether the next reply corrected itself is logged by a keyword heuristic (sorry / apolog / mistake / "not changed" ...) as `truth_corrected` on the flagged turn. Setting `truth_note` (default on). | Requested as optional; the heuristic is labelled as such. |
| 12 | 15:25 | `ScriptedStreamingLLM` takes an optional `answers` list (final text per turn; default "done", unchanged). | Needed to test agreeing and disagreeing claims. |
