Why support shows exactly zero difference (checked, not a bug): at the shipped threshold the
two-step rule adds a tool class at 32 of 171 VAL decision points, but every airline class maps
to the same server (travel_booking) in tools/tool_map.yaml / configs/cold_start.yaml, which the
next-step decision already warms; per server nothing changes. In coding the cost threshold at
lambda 100 is low, so the rule adds a tool at 4,260 of 7,353 copilot_2026 VAL decision points
(two-step probabilities: median 0.076, p90 0.122) and buys a little warmth for much more idle.

Decision by the pre-registered rule: lookahead 2 is NOT adopted for either profile; no
profile variant is added. Shipped defaults stay lookahead 1.
